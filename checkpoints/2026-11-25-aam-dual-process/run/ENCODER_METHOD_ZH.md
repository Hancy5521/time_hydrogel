# 跨环境的四坐标材料编码

同一材料在 A、B 环境各有四个独立重复。编码器对每种环境分别取早期局部特征的重复均值和标准差。窗口、时刻和观测量按主协议固定。重复观测的顺序无关，环境标签仍然区分。三个方法均以完全相同的向量作为输入。

## 共享规则的响应似然

设 (gin[-0.48,0.48]^4) 为引发、链增长、悬挂位点活性和桥连相对环化偏置。令 (z) 为跨环境局部响应向量，经开发数据标准化。以同一 (g) 预测 A 与 B 的响应
[
z = mu + B^	opphi(g) + eta,quad etasim N(0,Sigma).
]
(phi) 可包含线性项，或带更强收缩的平方及交互项。响应矩阵以岭估计拟合，残差协方差向对角收缩并带非零方差下界。不同环境的残差相关性保留在 (Sigma) 中。环境响应的共同成分和差异因而在同一个似然中参与识别，避免分别为 A、B 拟合两条可相互矛盾的材料码。该似然在响应空间是简化模型，协方差不随候选材料变化。

在白化空间中，令 (Q) 张成 (Sigma^{-1/2} B^	op) 的列空间。完整平方距离可分解为
[
|Sigma^{-1/2}(z-mu)-Sigma^{-1/2}B^	opphi(g)|_2^2
=|Q^	opSigma^{-1/2}(z-mu-B^	opphi(g))|_2^2
+|(I-QQ^	op)Sigma^{-1/2}(z-mu)|_2^2.
]
第二项与 (g) 无关。于是后验比值只依赖第一项。与规则响应正交的偏差不参加规则排序。在线性支路下至多四个投影方向，也可以小于四个。当某坐标的响应信号弱，概率权重可保留其不确定性。本方法不自动保证材料坐标的物理可辨识性。

在四维有界均匀先验上，使用 4,096 个固定的 Sobol 节点。计算预测残差距离后以温度化似然重加权。保留离散概率质量并作分层抽样，因此不强制采用单峰后验。复杂度、收缩与温度根据开发卡四折留出能量分数固定。每折训练、标准化和协方差估计独立完成。C 的任何观测和新材料真码都未用于这个拟合。

## 同信息对照与审计

岭回归和高斯 RBF 核岭用相同的 A/B 均值及标准差直接回归四坐标，超参数根据开发卡四折均方误差选择。利用折外残差估计坐标误差相关性，按有界相关高斯抽样，和候选方法具有同一有效码范围与相同的物理解码预算。解码依照原生反应场，不在编码器中直接对未观测的 C 轨迹拟合。
