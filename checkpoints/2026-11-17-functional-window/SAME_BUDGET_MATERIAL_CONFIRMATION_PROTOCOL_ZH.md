# 同预算局部含水读数与整体含水读数对照

**问题。** 在同一种分层水凝胶和给定湿润边界下，外部可见的整体吸水量相似时，一次背侧含水读数能否更早指出后续穿厚度导电与软化的时间差，并改变选择哪种层结构或开封条件。机制偏移模拟把主要瓶颈定位在早段水化与导电时窗。公开材料数据已分别证明几何与力学的时窗可分离、一个浴液的吸胀时钟可能迁移不佳。以下为拟执行的实物确认，无已完成实测。 [既有实物核查程序](PATCH_PROSPECTIVE_PILOT_ZH.md)

本次正结果使用的是**两个**早期时点和距湿润面 25%–50% 的内层平均。下述单读数是降低先导设备负担的候选，空间探头区间和测量时点需在先导批重新核定。如果两次早期扫描能在截止前非扰动完成，实物研究可首先确认同样的双时点比较。Gruber 等展示过单侧 NMR 的约 100 μm 步长剖面与凝胶水界面跟踪。局部水量的信号标定与实用采集速度仍由具体凝胶、设备和采集设置决定。 [NMR 原始研究](https://doi.org/10.1016/j.polymer.2023.126108)

## 同一个读数预算

1. 冻结一项早期时点 \(t_e\)，从试片首次接触已标定湿润边界的时刻计时。夹具首版拟用 \(t_e=300\) s。只有在设备先导证实这时仍在早期传质、两种读法均能在决策截止前出值时，才能把 300 s 写进真实确认协议。若不满足，用校准批重定该时点，再重新冻结。独立确认批共用同一个 \(t_e\)，不以各试片达到某含水比例来择时。记录开始、结束和上传时刻，量测时间使用同一个事前允许偏差。
2. 两种策略各只新增**一个标量、同一下单时刻、同一个出值截止**。整体策略读标准试片的单位体积平均含水 \(M_B\)，局部策略读同几何标准试片背侧预定窗口的含水 \(M_L\)，初始建议窗口为离湿润面 \(0.70\)–\(0.80L_0\) 的材料坐标。用不随吸胀漂移的边界标记和独立表面位置，登记实际探头响应核。两臂共用初始厚度、温度、浴液和前既有读数。不把其他空间像素、终点平衡称重、各臂之间的读数或未来导电数据交给预测器。
3. 能从同一无扰动定深 NMR 扫描估计整体与局部时，在开发阶段从一个扫描离线计算两个预定义统计量，工具相同、预测输入均限一个标量；这样比较信息价值。正式设备试验若用整片一次积分与单固定层一次采集，预先登记功率、扫描次数、时长、SNR 与延迟，匹配采集次数并报告各自实际成本。若两种来不及在同一截止出值，不能称同采样预算下的在线收益。用薄见证片代替主片时，两臂都用同厚度、同暴露边界的薄见证片，主片均使用同一目标厚度。若只给整体臂薄片，则几何改变会和局部测量效果混杂。 [单侧 NMR 水凝胶吸水测量](https://www.sciencedirect.com/science/article/pii/S003238612300438X)
4. 校准批可用多深度和多时点验证水当量。干态、已知含水标准、平衡质量与空夹具标定 \(M_L,M_B\) 的尺度、噪声、饱和、实际空间范围和温度依赖。含离子配方有不同核磁弛豫或阻抗影响时，基于实际配方和介质做同批独立标定。不要由导电读数反推含水作为“实测含水”输入。先按两个独立尺度记录实际吸水与电学恢复。

## 实物身份和可执行顺序

| 记录层级 | 执行要求 |
|---|---|
| 独立母批 | 独立称量和配制使用唯一 `mother_batch_id`。批内裁片和重复读数均保留母批号。若同混合料不同模具，还保留 `cast_id`。以母批分开发现、标定与确认。 |
| 主片 | `main_specimen_id` 在暴露前赋值，记录朝向、面积、厚度、夹具、候选和湿／弱湿。体相穿厚度电信号、整片水化能无扰动读取时记录该 ID 的实际时间轨迹；接触压力、频率、盐浓度以及几何校正随原始数据保存。 |
| 读数见证片 | 使用 `witness_specimen_id` 及 `parent_main_specimen_id`。保留重量或空间扫描对其本体读数的校准，开发阶段做主片—见证片一致性。见证片的预测输入不等于主片的同试片量测。正式确认可以选择同一主片的无扰动读法，或两臂都用同几何见证片。 |
| 破坏性替换片 | 软化、背层支撑或局部含水若需切割，事前把真实平行子片分配到 `candidate_id, environment_id, planned_time, channel`。每次只牺牲一个 `replacement_specimen_id`，登记对应主片和母批。不得把分别毁损的替换片结果拼成单试片联合轨迹。最初要评价的对象可以是同母批的候选面板，若要宣称单片全程联合达标，须有本体非破坏测量。 |

校准轮先用同批简化裸片及覆盖片测试两种厚度和两个已知湿润边界，观察实际早期读数是否随深层水动态改变。用于检验解耦的盐扰动与湿润边界需独立登记，并使用有相同处理的对照。模型训练和传感器量纲、窗口、设备常数全部从校准批确定。独立确认母批按批内配平安排作用环境与检测次序。冻结每种方法的候选、输出时间和输入散列后开始正式候选试验。湿和弱湿为平行试片。两种策略选了同一候选时共享其实际结果，以免重复样本或额外试探造成虚假优势。

先以一个预设时窗为主；必须固定窗起、窗末、背面支撑检查和弱湿不误触发检查，用独立湿态力学与电学读数计入。比较**整体单读数、局部单读数、无额外读数、同输入强经验模型**，全部使用同一候选库和同一动作成本。若要检验主动处方依赖，先确定两个事前合理且会在开发母批中互换优劣的动作。测量时间、操作量、已用量、未决和拒绝均入表。若模型没报或仪器太迟，按预注册的损失评分。空缺或分辨率跨阈值时报告判定区间。没有密集时间或变化速度边界时，评价限于计划采样时点。

阈值由实际器件用途和测量负责人在独立确认前定义。当前模拟里的无量纲软化、电学、时窗和安全代理只为工程筛选。功能片试验不推断植入生物相容性、组织结果或临床安全。

## 样本量和判定

先用校准母批估计成对的母批级决策损失差 \(D_i=L_{\mathrm{bulk},i}-L_{\mathrm{local},i}\)、父批方差及母批内缺测率。确定工程上有意义的最小差 \(\delta_{\min}\) 及预期检验功效后，可用 \(n\approx[(z_{1-\alpha/2}+z_{1-\beta})s_D/\delta_{\min}]^2\) 作初估，再作带组内重复和实测缺失概率的分组重采样或功效计算。二元达标可用配对不一致率估计精度。重复时间和见证片增加测量信息，不能增加独立母批数。公开资料目前没有可用于填现实最小效应和 \(s_D\) 的独立配对母批。若同预算局部读数不能预测真窗口或不改变决策，保留该否定结果，以排除把更细空间观测本身当成应用收益。 [实物验证接口与删失评分](PATCH_PROSPECTIVE_PILOT_ZH.md)
