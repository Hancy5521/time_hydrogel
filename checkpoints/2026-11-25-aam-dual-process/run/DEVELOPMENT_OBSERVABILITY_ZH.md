# 开发样本的局部拓扑可辨性诊断

对已有 128 张开发规则卡按字段回读。未增加模拟、未使用盲测代码或 C 的轨迹，也未重训或改变任何超参数。A、B 各使用每卡四条真实生成的模拟见证轨迹。将每张卡里的四条可见观测取平均，再检查此平均量与四个真实有效规则坐标的 Pearson 相关，仅作观测可辨性的探索。

| 规则坐标 | 最大绝对相关的观测 | 绝对相关 |
| --- | --- | ---: |
| 引发 | A，时刻 0.65，局部 AAm 转化 | 0.503 |
| 链增长 | A，时刻 2.05，局部 AAm 转化 | 0.385 |
| 悬挂活性 | B，时刻 2.05，可见 MBAA 已双位点反应比例 | 0.398 |
| 桥连偏置 | B，时刻 2.05，局部图的冗余连接量 | 0.198 |

上表选的是 (2	imes3	imes14) 个相关系数中的最大绝对值，不能当作未见验证效应。桥连偏置与局部冗余连接量的相关符号为负。早时刻 0.65，冗余连接量为零的单条轨迹分别占 A 中 92.0%、B 中 96.1%。到截止时刻 2.05，两者分别为 64.3%、54.5%。双位点反应量也有大量零值。成网信息稀少可以解释桥连坐标的弱信号。提高可见性后，能否提升独立预测及材料编辑，需要通过等观测数强基线验证。

自然的干预是在材料码校准单独使用 A、B 的晚些见证样本，仍只使用三帧同尺寸空间窗口，C 待设计样品不事先观测。另一个对照是延续固定时钟，但使用能保留冗余连接或做出链归属的可见域。真实实验中这两种选择的可测意义应分别审查。
