- **静态菜单**沿用已登记的 13 个编辑，包括不编辑以及引发、增长、悬挂位活性与桥连偏置的正负编辑。固定原 C 环境，末次 MBAA 投料时刻 1.95，迁移率在 1.775 由 .19 变 .34。
- **分时菜单**固定迁移率曲线、单体数、总投料和反应模型。测试提前或延后补投同一批六个 MBAA，以及两种把部分引发从早段移到后段的分时规律。其已知引发强度乘子的 [0,6] 积分均与基线相同。各候选与三项静态可匹配编辑组合，零码、增长增强、引发和增长增强。固定规则码在单条路径内不改变。
- **选择**对新随机抽取的 16 张母卡，先用各 8 个随机初态模拟所有候选。材料规则从原先验四维独立 U[-.48,.48] 抽取，不使用母卡个体观察。两个目录分别按联合达标率、平均最窄裕量、固定候选序号排序。把所有候选预测和两个目标的选择封存。
- **确认**用不同的 32 张母卡和每卡 24 个新初态从单体重启，评价各目标冻选、零动作，以及最优分时条件对应的同码原工艺、同工艺零编辑。开发、确认和 bootstrap 随机角色分开。不同动作共享初始抽样、布朗格点、等待与标记的随机地址。验证仅作母卡级配对，24 次重复不当作独立母卡。以下降级须保留：目标可改善但不足可靠；删除固定码或分时操作不损失；某些目标仍不可达。
- **主效应**是延迟赶上目标下最优分时与最优静态菜单选择的确认成功率差。早进目标与未编辑对照、同码/同工艺消融均为副比较。比较预先固定，给母卡配对 bootstrap 95% 区间。绝不以确认结果替换选择。独立回放确认每卡首个随机初态的所有验证动作。
