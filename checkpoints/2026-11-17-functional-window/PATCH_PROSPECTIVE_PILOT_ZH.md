# 定时水凝胶的原创性复核和实物验证入口

现有原型用低维状态恢复随深度和时间变化的水化、键合与载流过程，再根据用户指定的时窗选层序、厚度和开封设置。上轮留出模拟中，时空恢复误差相对同输入核岭回归降低约 36%，跨三种时窗宽度的选材达标率在两组分别多 4.34 和 3.82 个百分点。最窄的载流偏移任务已有固定选材胜出的反例。 [既有结果](PATCH_MEMBRANE_PROCESS_ZH.md)

## 两项实际吸水数据揭示的标定风险

1. Díaz-Marín 等的 PAM–LiCl 环境箱数据允许用 2.34 mm 标准片的早段校准，然后冻结预测到两个不同厚度。三种湿度条件共用各自预先给定的标准片吸湿幅值。对 3.2 mm 厚片，有限传质 MAE 为 **0.02360 g/g**，同输入最佳对照（平方厚度时标）为 **0.02150 g/g**。对 1.2 mm 薄片，有限传质为 **0.04746 g/g**，同输入最佳对照（线性厚度时标）为 **0.02467 g/g**。两个最强对照随方向改变。独立解析核查和工作簿读回通过。厚度组留出有实测数据支持，其制备母批独立性未知。本项测的是开放表面的吸湿。 [原始研究](https://doi.org/10.1038/s41467-024-53291-5) · [数据追溯与复现](PATCH_MEASURED_UPTAKE_TRANSFER_ZH.md)
2. Nečas 等 10 个烘干 PVA 圆片中，按 0–6 h 校准、24–72 h 核对时，圆柱扩散的晚段 MAE 在两组分别为 **0.20955 g、0.13680 g**，作者采用的一阶动力学为 **0.01824 g、0.10061 g**。所有圆柱拟合触到扩散速率搜索下限。早期已拟合好吸水幅度与扩散速率的组合，仍不足以分别确定这两个量。首次试读 CSV 时，错误的分隔符使全行被打印，因此这组重分析为回顾性探索。全部行及失败结果保留。 [开放称重数据](https://doi.org/10.5281/zenodo.15053243) · [结果与数值检查](runs/necas_open_uptake_20261116/UPTAKE_RESULT_ZH.md)

两项数据都缺少当前任务所需的同批封层、开封、软化与导电终点，无法判定 75 结构的湿／弱湿选材效果。它们直接支持一个设计决定：首先独立测平衡容量，至少用两种初始厚度区分界面传质和内部扩散，然后才把封层标定用于新批时窗。早期局部读数保留，但不能用同一条短曲线确认所有物理参数。

## 先导实物试验如何执行

1. **标定量纲与边界。** 在湿、弱湿条件分别记录源侧实际水活度或 RH、温度、几何面积、预湿初始厚度及暴露零时刻。先做夹具空白、近乎不透水的参考、无遮挡接收片。无遮挡建议同批两种厚度，每种测早段、一个较晚时点和平衡容量，预留独立同类几何检验厚度迁移。覆盖片单独测接收侧进水量，保留封层自身蓄水的独立记录。开封用光学、示踪或独立物理标记，保存最后闭合时间与首次开启时间，未开启则记录右删失。开后通量另测，按实测结果检查是否可共享两种环境参数。
2. **保持量纲标定与确认分批。** 在校准批固定独立的参考时间 $t_0$、厚度 $L_0$、模量 $E_0$、体相电导 $G_0$、含水和容量映射。若接收侧质量差以每面积表示，模型质量尺度是 $L_0\Delta C$，其中 $\Delta C$ 为独立标定的体积浓度差。相应 $D^*=D t_0/L_0^2$、$K^*=K t_0/L_0$。不得用待评分材料的未来目标点定义尺度。确定裸片水化、刚度和电导的时空采样位置。本项目先前的无量纲阈值、本体电学代理和 ±15% 波动来自仿真，实测的阈值与容差应在先导确认后按目标用途登记。
3. **同批选材并冻结。** 给各方法同样六个早期物理读数、同一个可制造目录和同样校准。主方法和有足够开发批的同输入统计基线各只报一个候选，普通固定设计作为额外基线。无可用预测也登记。记录每条读数真正可用的时间。所有选材先冻结，再启动候选正式暴露。用同一件候选的结果评价所有选择它的方法。湿和弱湿使用独立平行试片。破坏性测量使用预先分配的同批兄弟片。三个新母批只能作为可行性先导，不能据此宣称有足够功效。若两种方法选择两个不同结构，每批基本面板为两个结构 × 两个环境 × 两组平行重复，另加标定用的标准片。
4. **按目标时间判定。** 直接记录干态前、背面刚度，湿目标窗起点的前面刚度，截止时的前面刚度与体相穿厚度电导，后续两条终态条件，以及事先登记的背面支撑和弱湿不误触发时间格。实际记录离开截止时刻的间隔以试片暴露 UTC 计算。应记录接触校准、夹具压力及原始光学或阻抗信号。湿与弱湿的暴露条件和各自零时刻使用同一记录规范。单点只能支持规定测点的合规结论。若需连续时段保证，提前定义记录密度和可验证的单调或速度边界。

开封时间应与接收侧质量分开获得。已有定时胶囊实验用质量和独立染料标记区分吸水与释放。独立的穿透电学测量还要核对探头接触和电极极化。 [开封标记实物先例](https://pmc.ncbi.nlm.nih.gov/articles/PMC8004877/) · [穿厚度阻抗测量先例](https://doi.org/10.3390/membranes9050062)

## 本地冻结和评分程序

`validate_hydrogel_pilot.py` 接受三个冻结输入。`PROTOCOL.json` 为带量纲的阈值、校准母批、方法版本散列、目录、平行批和时间格。`REQUESTS.json` 为批次、目标时窗、决策截止、最早准许暴露时刻和六条读数及其可用时间。`CHOICES.json` 是逐请求的候选编号或 `null`。研究者需另外保存散列匹配的实际标定及方法文件。评分器核对本地记录。盲法执行由仪器日志或独立人员托管的冻结收据确认。

真实列 `OUTCOMES.json` 采用 Pa、S、秒。每条注明母批、候选、平行面板、湿／弱湿、试片编号、通道、计划时刻、实测上下界、试片暴露 UTC 与采集 UTC。无结果使用 `low/high=null` 并附原因，或保留在注册面板中等待。需要单独保存开封标记原始记录及夹具校准。评分采用暴露 UTC 推出的实际时间和一个时间容差，避免填报相对时钟与 UTC 各加一次容差。局部审核曾复现这个问题，修正前源码和收据保留。

阈值范围完全满足为 `pass`，有一条明确不满足为 `fail`，缺测、过晚或区间跨阈值为 `unresolved`。无输出的策略记为 `no_decision`，在端到端达标中记 0。若两个方法选同一结构，即使测量结果不全，两者的配对差仍为零。不同结构的结果区间为 $[L_p-U_b,U_p-L_b]$。先在母批内处理多个请求和重复，再跨母批等权，保留所有未决项。

```powershell
# 只用固定合成面板验证程序。输出到新目录。
python -X utf8 -B audit_validate_hydrogel_pilot.py pilot_software_replay

# 以下由实验人员填写真实带量纲输入。保留两个阶段的原始文件。
python -X utf8 -B validate_hydrogel_pilot.py freeze PROTOCOL.json REQUESTS.json CHOICES.json FROZEN.json
python -X utf8 -B validate_hydrogel_pilot.py score PROTOCOL.json REQUESTS.json CHOICES.json FROZEN.json OUTCOMES.json SCORED.json
```

字段实例见 [合成协议](runs/hydrogel_pilot_validation_20261116/SYNTHETIC_DEMO_V2/PROTOCOL.json)、[输入](runs/hydrogel_pilot_validation_20261116/SYNTHETIC_DEMO_V2/REQUESTS.json) 和 [逐读数实例](runs/hydrogel_pilot_validation_20261116/SYNTHETIC_DEMO_V2/OUTCOMES.json)。示例日期、参数和结果仅用于代码回放。尚未用该程序给任何真实定时水凝胶设计打分。

## 复现实测吸水组件

吸水代码使用 Python 3.13.5、NumPy 2.1.3、SciPy 1.15.3。环境箱独立工作簿审计还需要 `openpyxl`。公开 PVA 数据原件和 CC BY 4.0 原作者说明随包提供，只抽取原 9.8 GB ZIP 内的必要成员。环境箱大工作簿独立许可未核实，工作簿原件已保存在本机相应的 `SOURCE.xlsx`。解压审阅包后，按 [数据追溯说明](PATCH_MEASURED_UPTAKE_TRANSFER_ZH.md) 的原出版方地址及 SHA-256 取得工作簿。上一轮全量仿真资源保存在独立文件 本地历史快照。

```powershell
$pva='runs/necas_open_uptake_20261116'
python -X utf8 -B patch_necas_uptake.py freeze "$pva/UPTAKE_REGISTERED.json" "$pva/Figure_3_Swelling_kinetics.csv" uptake_frozen_replay.json
python -X utf8 -B patch_necas_uptake.py score "$pva/UPTAKE_REGISTERED.json" "$pva/Figure_3_Swelling_kinetics.csv" uptake_frozen_replay.json --score-out uptake_scored_replay.json
```
