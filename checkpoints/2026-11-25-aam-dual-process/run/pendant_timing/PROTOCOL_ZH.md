# 局部化学事件的时序调制

前一轮改变引发与补投，保留了早进目标的额外收益，但晚补投未稳定改善延迟—赶上目标。这次保持上级冻结的晚成网目标及时间不变，检验更直接的微观控制。

仅把模型中悬挂 MBAA 位点的二次反应原始速率乘以已知外场 m(t)，包括桥连与闭环共同缩放。初次单体接入、AAm 链增长、引发与迁移律沿用 C，末批 MBAA 仍在 1.95 投料。拟测试的四种控制为切换时刻 2.85 或 3.50 与前段乘子 0 或 .25 的交叉。后段乘子由积分守恒计算，使积分与恒定乘子 1 的基线相同。实际危险量和转化可能不同，积分相同只约束外场预算。材料规则码仍固定。此门控是虚拟有效动力学，未指认可实现的现实化学。

开发采用 16 张新材料卡×每卡 8 个独立随机初态模拟所有门控与两个静态方案；按联合达标率、平均最小裕量、候选序号冻结唯一门控。确认用 32 张新的 [-.48,.48] 四维统一先验独立卡，每卡24个新初态，原 C 无编辑、原 C 引发坐标减 .48、冻结门控三组从未成键单体起步。三组共享初态、布朗格点、等待/事件标记地址。同步比较终段网络、等转化团簇与时间，设置不可达保留记录。阴性结果不替换目标、门控、代码范围或随机种子。若联合成功率相对两个基线的母卡配对区间下界均大于零，并且相对较强静态对照的点提升至少 5 个百分点，才说延迟目标有实用确认收益。区间为每项配对 bootstrap，副指标用于解释。

验收独立重放每卡三组首个随机初态反应日志，随机角色必须与同轮原试验、分时补投及这里的计划种子互斥。报告精确预测锁、日志、样本并说明一切结果均为原生微观模拟。禁止回调本案后的目标或门控。
