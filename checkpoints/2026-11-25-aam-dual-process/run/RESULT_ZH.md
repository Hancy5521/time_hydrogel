# 从单体成链成网、识别材料规则到按过程逆设计

## 本轮闭环的构成

1. **从单体生成微观历史。** 64 个 AAm 和 14 个 MBAA 以未接键状态起步。原生随机反应场推进布朗运动、引发、普通链增长、MBAA 接入及第二位点反应。每次合法成键改变位点占用与图，谱系、团簇和周期绕行分别计算。从同一卡各个规则编辑重新生成完整起点。
2. **用局部观测推断固定规则。** 同一种规则在 A、B 两个已知不同投料和引发历史中保持固定。编码器每种工艺看四个独立样品，每样品看 .65、1.35、2.05 三个约占总体积 34.3% 的立方窗口，保留可见粒子、转化和诱导图。早期观测未包含隐藏反应候选、全局键、未来状态。指定位点码分别控制引发、链增长、悬挂双键活动和桥连相对团簇内接键的偏置。
3. **让同一代码在新工艺 C 中执行。** C 的外部迁移率历史已知，非零代码的 C 完整轨迹独立生成于冻结之后。所有学习模型使用同一个原生解码器。候选模型的共享响应编码依据 A/B 两历史在各规则下共同出现的统计响应反推分布，允许不同规则解释同一组局部读数。
4. **给定时间目标，冻结编辑，再从单体重启。** 两个目标有相同的早期链长底线，分别要求中段形成更大的团簇并到达终转化，以及中段小、终段成长。阈值由独立零码 C 锚点决定。13 个编辑覆盖四轴的正负变化及引发与增长的组合。共 36 张全新规则卡、每编辑 16 个同随机地址的配对重启，全部 7,488 条保留。每个被选编辑的首条路径和零码对照首条路径保留可重新推导事件的日志。 [登记](REGISTERED.json) · [流程协议](PROTOCOL_ZH.md) · [前向与逆设计冻结](FROZEN.json)

## 微观成网已经完成数值核查

7,488 条都发生反应；6,539 条出现跨团簇桥连；928 条在终点跨周期盒绕行。用不同图实现独立重放了保存的全部 229 条原生事件日志、19,866 个事件，1,374 个快照与 458 个等转化里程碑逐值一致。配对的模拟材料基因和初始创新在结果中可追溯。总量、链谱、跨团簇事件与绕行属于不同的观察量。 [事件与图独立审计](AUDIT_RAW.json) · [模型和统计复算](INDEPENDENT_SCORE_AUDIT.json)

**固定码确实能改变网络接法。** 同一基底下只变桥连偏置，末段跨团簇桥连数除以投料 MBAA 总数增加 **2.48 个百分点**，95% 配对区间 **[2.02, 2.94]**；最大团簇比例增加 **2.96 个百分点**，区间 **[2.13, 3.77]**。总转化率差的区间跨零，绕行的增益也未建立。达到相同 60、76 消耗位点的配对，在该时刻最大团簇占比分别增加约 2.01、2.98 个百分点；共同达到分别有 566/576、464/576 对，描述限于该条件子集。 [分界、配对与编码结果](SCORED.json)

## 数值误差是否改变快速设计结论

另用 128 张新代码卡，保持起始、布朗运动与事件随机序列完全配对，将时间步从 .025 减为 .0125 和 .003125。快速编辑相对零编辑改善分别 **27.34、28.91、22.66 个百分点**，均有正的配对 95% 区间。延迟目标三种步长均无确定优势。终态转化、重均链长和桥连多数在预设绝对误差内；绕行概率相对细网格的区间仍未满足 ±7.5 个百分点收敛范围。快速编辑的联合达标支持跨网格复现，罕见绕行的精确发生率仍应使用明确的分辨率和数值误差界。 [步长登记和评分](resolution/SCORED.json)

## 低维局部状态能恢复多少空间信息

在额外 640 条开发和 192 条盲测 C 轨迹上，把周期盒分成 64 个空间单元。输入三个时刻的 8 个可见单元及同等公开的模拟真材料码，输出全盒 AAm 数、已反应 AAm 数与已占用 MBAA 位点数，分别评价截止同刻和未来三个时点。在截止时保留原读数，每帧 AAm 总数由显式守恒投影保持 64。细节模型在低秩响应中预测增量。锁住预测后再从相同独立地址重放验证，所有前缀读数逐值一致。此试验的真码为共同输入，隔离要测的是局部状态的额外信息。

| 方法 | 截止同刻隐藏单元 MAE | 未来隐藏单元 MAE | 未来全盒 MAE |
| --- | ---: | ---: | ---: |
| 体积平均 | 0.46184 | **0.62116** | 0.73277 |
| 已知真码核岭 | 0.45989 | 0.62259 | 0.73555 |
| 真码加局部数据直接核岭 | **0.45848** | 0.62446 | 0.72410 |
| 真码加局部数据低秩补全 | 0.45945 | 0.62308 | **0.72291** |

相较只知道真码的对照，低秩方案使未来全盒平均误差降约 **1.72%**，差值区间 [−0.01647,−0.00904]。把评价限于未观察的 56 个单元后，改善没有建立，简单体积分布还更准。低秩与同信息直接回归对全盒的差为 −0.00119，95% 区间 [−0.00271,+0.00030]。当前闭环的空间能力限于统计场；模拟器允许多条相容的不可见微观历史。原程序因 Windows 共享 Numba 缓存序列化失败，未输出预测或标签。另登记隔离缓存后保留同样随机角色与方法，同时修正评分索引的维数次序。 [空间验证](spatial_completion_retry/SCORED.json) · [独立复算](spatial_completion_retry/INDEPENDENT_AUDIT.json)

## 工艺时间是与固定材料码不同的控制量

在与首轮完全分隔的 32 张规则卡和 4,608 条验证路径上，固定同样的引发与增长码，提高早目标达标率的一个办法是提前 MBAA 投料。提前投料的冻结方案 **413/768 达标**，原投料同代码 **344/768**，零编辑 **151/768**。配对收益 **+8.98 个百分点**，95% 区间 [4.43,13.41]。单独推迟投料将中段变小的约束通过率由约 41.1% 提高到 53.1%，也使终段追平约束从约 58.1% 降到 53.8%，联合目标未明显优于静态对照。 [分时工艺确认](scheduled_edit/RESULTS_ZH.md)

## 从成键历史计算一个结构功能代理

将带实际周期位移的合法共价图当作每条边单位导通的网络。解周期 Kirchhoff 方程可量化某个时刻有没有贯穿通路，以及不同通路并联给出的相对传输能力。用两张明确的早／晚窗口冻结条件。再用 24 张新规则卡和 3,456 条路径验收，两个窗口均有成功实例。共享编码选择分别成功 21/384、9/384，统一工艺为 21/384、20/384。现场模拟分支没有显示编码带来改善。216 条原始日志的 1,944 个时空轴值由另一线性代数实现复算，最大差约 (5.55	imes10^{-17})。该输出表示结构传输容量；实际载流子、溶剂、离子运移与力学功能还需相应模型及实测。 [结构代理逆设计](transport_proxy/RESULT_ZH.md)

## 后移观测能否改善最难辨识的桥连码

先以同一批配对路径的两个等预算观测方案比较，三个早时点为 .65、1.35、2.05，三个后移时点为 2.05、3.50、4.85，空间视野和样本数固定。

- 对 48 个新规则配对，在其它坐标相同而桥连码取 ±.70 时，RBF 后移观测的 MSE 为 0.46904，早期 0.49069，下降量区间 [0.00479,0.03754]。两个方向正确排序由 24/48 升至 36/48。截止局部图中没有冗余连接的比例随观测后移从 62.8% 降到 30.5%。 [符号识别验证](topology_witness/RESULT_ZH.md)
- 对另 56 张连续新规则卡，RBF 后移的桥连码 MSE 从 0.18303 降到 0.14357，改善 **21.6%**；对照固定零码为 0.13929，未超过它。在 C 中提供其余三个真实码，以隔离桥连码变化影响。桥连和链长的联合过程分数由 0.25613 降到 0.25533，约 **0.31%**，下降量的 95% 区间 [0.000055,0.001576]。固定桥连码的点估计 0.25491 更低，末端桥连和团簇误差未见明确提升。连续闭环结果支持主动选择更有信息的观测时刻，当前证据仍不足以采用个体桥连估计。 [连续迁移验证](continuous_bridge_transfer/RESULT_ZH.md)

## 延迟目标的关键是控制第二反应位点何时打开

早先推迟投料同时减少前段连网与末段追赶能力。新增的虚拟工艺保持投料、基础成胶场、其余反应与总时间积分倍率不变。将悬挂双键第二次反应的倍率在 3.50 前设为 0，之后为 2.4。用离散候选预测并冻结该门控，随后从单体在独立 32 张材料卡与 24 组配对样本上重启。

| 延迟后追平 | 达标 | 比例 |
| --- | ---: | ---: |
| 无干预 | 67/768 | 8.72% |
| 原最优静态引发编辑 | 78/768 | 10.16% |
| 第二位点分时打开 | **277/768** | **36.07%** |

相对原最优静态编辑，绝对改善 **25.91 个百分点**，配对 95% 区间 [22.01,29.43]。这支持在该模型内先让单体长成链，再加速可用的二次交联。96 条原生样本事件日志逐值重放。这个干预是对可执行模型的反应率调制，能否用特定反应化学实现同等的选择性和时序还没有实物数据。 [延迟成网冻结结果](pendant_timing/SCORED.json)

## 最终配对确认：同一套单体起点，两张相反的成网时间表

冻结早目标采用提前投料与提高引发／增长，晚目标采用第二位点分时打开。两方案使用原登记的目标。另取 48 张新规则卡，每张 16 组配对随机地址。对同一配对地址，从相同未成键的粒子和引发预算分别模拟两种干预以及三个对照，采用比选案阶段更细的 .0125 网格。3,840 条路径、五个分支均按照冻结选择运行。

| 验收目标 | 对应静态编辑 | 两套分时方案 | 配对改善，95% 区间 |
| --- | ---: | ---: | ---: |
| 快速成网 | 365/768 | **445/768** | **+10.42 个百分点** [5.60,15.10] |
| 延迟后追平 | 61/768 | **267/768** | **+26.82 个百分点** [23.70,29.95] |
| 两个目标在各自的配对分支均通过 | 34/768 | **176/768** | **+18.49 个百分点** [14.97,21.88] |

配对联合指标指同一随机地址的两条单独运行分支分别达标。去除同地址的交叉项，估计独立地址下的双目标达标率为 21.03% 对 3.87%，配对改善区间 [14.18,20.17] 个百分点。 [独立地址核算](final_paired_process/INDEPENDENT_ADDRESS_DIAGNOSTIC.json)两条目标轨迹的中段最大团簇差为 14.30 个百分点，区间 [13.39,15.25]。终段追平仍以原目标的下限定义。最终 240 条原生样本日志、21,243 个事件可逐值重放，程序复算全部 21 个评估区间。 [最终冻结](final_paired_process/FROZEN.json) · [最终配对报告](final_paired_process/RESULT_ZH.md) · [最终评分](final_paired_process/SCORED.json) · [独立核查](final_paired_process/INDEPENDENT_AUDIT.json)

## 完成范围及缺失的实物证据

这一套程序把从单体起步的反应场、可执行的固定四维规则码、局部观测反推、时间过程选案和独立重启回验接在一起。**快成网／推迟后追平的群体模拟逆设计已通过同一批起点的配对和时间步复验。** 规则可编辑性得到正结果。四轴的个体可辨识性和增加的逆设计收益未达标。空间只验证到可见区辅助的统计计数，隐藏区精度仍缺少优势。功能读出目前是单位边图传输容量。

真实配方到这些代码及第二位点门控的映射仍缺乏校准。需要对应到同一母批的原始可见时空读数、实际候选工艺、独立结构／力学数据和样本身份。已核查的公开资料可以检验部分转化、链长或流变，无法覆盖这一整条配对验证。 [外部来源证据](EXTERNAL_EVIDENCE_ZH.md) · [复现入口](REPRO_ZH.md)
