# 预冻结模型的独立规模复验

前一轮的移动视野明确优于同卡固定视野，且超固定四维的区间上端仅高于零 4.85e−5。连续幅度的 C 工艺上限较弱，故这次只复验两档强干预总体及固定模型。不开新超参数搜索，不再使用已消费的 112 卡，也不改变两张已有时间表。224 张新卡，每卡两种方向独立观测、四个 A／B 重复，所有经典同信息模型沿用其原来的训练、核权重和温度。预测概率先冻结。检验 C 的两种既有工艺和两档变化，基底四坐标给全部候选作为隔离控制。预测和验证各 16 个新的配对地址。所有路径均从未接键单体起步。

主指标仍为桥连＋最大团簇多帧公平能量。主要对照是固定四维。冻结部分似然只有在相对固定四维的配对 95% 区间上端低于 0，才作为这一受控总体的预测提升。对同信息直接核岭报告绝对差及区间，实用近似带上限 0.00075（约为固定四维分数的 0.3%）单独报告，未达到此带时不宣称确定接近。保留固定视野、未知方向等权混合及告知真方向。同一材料基底的两种物理方向，用相同模拟地址配对仍按基底卡作为独立样本。强幅度模拟、理想化采集和已知四个基底参数的假设不变。无实测新增。
