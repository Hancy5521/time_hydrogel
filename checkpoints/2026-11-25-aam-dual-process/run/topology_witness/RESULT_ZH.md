# 观测后移使模拟桥连符号更容易区分

同一条从单体出发的原生轨迹保存了五次局部快照。早期方法使用 .65、1.35、2.05 三帧，后移方法使用 2.05、3.50、4.85 三帧。空间窗口、每个环境的四个独立重复、训练卡和模型超参数预算一致。80 对开发和 48 对留出材料的前三个规则坐标从相同随机背景配对，第四坐标为 ±.70。一个配对内用共同的起始位置、运动与反应随机地址。各配对用独立地址。独立审计共核对了新旧 4,136 个地址，未发现跨阶段复用。

| 桥连坐标估计 | 配对 MSE，低为佳 | 同背景下正号码排在前面的频率 |
| --- | ---: | ---: |
| 零码常数 | .49000 | 24/48（将平分计半） |
| 早期岭 | .48927 | 28/48 |
| 后移岭 | .46136 | 35/48 |
| 早期 RBF | .49069 | 24/48 |
| 后移 RBF | .46904 | **36/48** |

后移 RBF 相对同算法早期观测降低 MSE **.02165**，约 **4.41%**，按独立材料背景配对的 95% 区间为 [.00479, .03754]。它相对零码常数也改善，区间 [.00348, .03801]。后移岭的 MSE 降幅为 .02791，方向一致，95% 区间 [−.00583, .05954] 包含零。因此已得到**一项同预算的正向观测选择证据**，两种方法均独立确认改善的更强结论尚不成立。

为何可能更好？可见诱导图冗余连接为零的比例，在 2.05 仍有 62.8%，到 4.85 降至 30.5%。可见双位点反应量为零的比例也从 38.8% 降至 8.1%。观测中出现了更多可用于判断接键类型的结构。分析对的是指定合成体系中相隔 1.4 的两个模拟坐标，早期工艺环境单独产生见证样本。未用 C 的未来或父轮留出卡拟合，因而未证明同样可恢复连续桥连码，也未证明在 C 的逆向选择会因此变好。
