# 可见时空接键变化与拥挤度规则

上一轮原生仿真只有在给出真实拥挤度响应方向时才有预测增益。这次比较观测内容，保留相同三帧和同一局部视野。对象仍是从单体、链到网络及两个已封存过程。

前体卡有相同的四个基底参数和两种只作用于非空邻域的相反规则。它们分别在已知 A/B 环境以每环境四个局部重复生成。144 张拟合、64 张开发选择、96 张独立留出，分组不重叠。场景为计算压力测试，拟合时可使用模拟方向标签。每张卡两个相反分支共享随机地址。模型预测某个分支只能读取该分支的窗口。按真实日期写登记后生成数据。

仪器假设为可确定同一可见节点 ID、位置、物种、双键位点占用和双端都在视野内的接键。每次使用三帧、0.70 边长的立方窗口。候选计划为标准早、标准后移、两套短间隔和一套长区间；用同一原生嵌套时间格按三个时间位置取子集，单模型只读取被选的三帧。开发选计划，确认不换帧。

两帧共同可见的 AAm 和由单占位变双占位的 MBAA，允许从可见无向边多重集识别新增接键。只在前帧近邻且中点球完整落在视野内时，比较当时空／非空邻域。若当时两个节点由局部路径相连，这次关联可称局部闭合。其余只是视野内未连通，不是确认真桥。前帧近邻是接键时邻域的带误差代理，不读取事件簿、真占据、真实团簇、隐藏边、活性链端或后续轨迹。相同可见监控对象按四组统计被观察的潜在接触与新增事件数。

候选编码使用开发拟合卡的局部条件计数残差，去掉候选接触曝光量的主要影响；通过同基底配对投影在低维空间学习正负响应方向。与原快照摘要、相同可见转移计数的核岭与岭、固定先验比较。报告每种方案单分支概率的 Brier 与准确率，同卡两方向排序为诊断。需要在新的 96 卡上降低同输入核岭的 Brier，且单分支准确率超过随机 5 个百分点、区间下界高于零，才采用专门编码。若更好的同预算信息能够被通用分类器利用，也记录观测贡献并另用新 C 随机地址验证最强已冻结方法。公开实物测量或真实观察平台均未新增。
