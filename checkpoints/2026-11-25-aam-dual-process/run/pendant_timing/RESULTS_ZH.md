# 延迟成网后赶上，可以由悬挂位反应时序改善

延迟目标原样沿用上级冻结。需要在 2.05 已形成足够长的 AAm 谱系，3.50 控制最大反应团簇不超过 18/78，6.0 的最大反应团簇至少达到 26/78。固定 64 AAm 与 14 MBAA 的单体预算、C 的迁移率、补投时点以及四维材料规则码。分时外场只调节所有合法悬挂双键的第二次反应速率，相对桥连和回接的固定材料偏置保持。

四种候选用 16 张新规则卡各 8 个初态选择，**冻结策略在 3.50 前设悬挂位的二次反应乘子为 0，随后至 6.0 设为 2.4**。外场积分与恒定乘子 1 均为 6。两种虚拟操作并不具有相同的实际反应危险积分，因为后者也由当时的链、位置及可用位点决定。直接核查 32 条保存的门控事件日志，切换以前二次反应事件为 0，之后出现 334 个。材料早期 2.05 的重均谱系长度门槛达标率仍为 78.4%，零编辑对照为 77.3%。

确认使用 32 张未见规则卡、各 24 个独立随机初态。对同一母卡和初态的三个物理分支实施配对。联合达标率由较强静态对照的 **10.16% 升至 36.07%**，母卡级配对增加 **25.91 个百分点**，95% bootstrap 区间 **[22.01, 29.43]**。相对未编辑的配对增量为 **27.34 个百分点**、区间 **[23.83, 30.73]**。通过预定的 5 个百分点与两项区间下界大于零的判据。

**机制解释。** 延后投入最后一批 MBAA 仍允许已在场的交联剂先完成第二次反应，较晚增加材料也可能无法追回终点。暂时限制悬挂位反应，则保留早期形成链与交联剂接入，随后在相同投料下释放二次反应。独立数据支持的是这个虚拟作用机制及对应的模拟目标。母卡联合达标率仍为 36%，个体材料码预测暂无额外选案收益的证据。现实体系需要可标定的选择性控制，才能把这一干预的物理时间、幅度和制备可行性带入实验。
