# 从可见几何重建候选风险的替代

记数法无法替代已知候选风险。新方案对同一移动局部窗口，从可见点、已占用位点数和可见图估计一个几何候选池。可见 AAm 或 MBAA 来源有任何已占位点，目标是单占位的 MBAA 且距离小于原模型捕获半径。这个近邻规则会包括已失活来源，因此只是机会的近似。所有候选须有完整中点球，用局部闭合证书或无出界键的相离证书。使用标称桥连和两种闭合的均值作为参考权重。当前反应的类别仍由局部真正成键及上述证书决定。这种观测不读取反应活性、全局候选集合或候选谱系标签。设备要求持续定位事件、查看局部运动与边缘线段，仍是理想的合成可视读数。

同时记录完整校准方案以公平比较，预算各三。新 96/48/80 张独立卡验证方向，不增加真值机制幅度。使用几何候选条件似然和同输入学习基线，温度等超参数只从开发数据选择。Brier 相对原完整采集的差上界要求低于 0.010，且准确率 ≥55%、区间下界 >50%，才继续独立 C 过程。若失败，说明可见几何与占位对当前任务还不足以还原可靠反应风险。实际测量需标定遗漏反应位点及可见路径。
