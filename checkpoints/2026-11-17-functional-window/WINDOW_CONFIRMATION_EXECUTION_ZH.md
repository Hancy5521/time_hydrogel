# 实物时窗验证的记录与执行

验证问题是同读数数量下，局部含水信息能否改善整体服役时窗。候选试样首先需要在位保持支撑与低导电，随后在规定工作时窗同时软化并满足穿厚度导电。弱湿条件则需要避免误触发。水化见证片只提供早期输入。实际工作时窗的测量来自相互独立的湿和弱湿主片。

## 可以直接执行的记录接口

运行 `validate_window_confirmation.py`。它从与上一版相同的结果区间判定函数重用缺测、迟测和跨阈值规则，检查工作窗内**每个登记时点**。其中包括安装段低导电和背层支撑、工作段穿厚度导电和前层软化、弱湿段低导电。末端实测达标而中段失败时，整个窗口判作失败。未测中段或仪器区间跨阈值时保留未决。

1. `PROTOCOL.json` 固定真实时间格、量纲阈值、候选 ID、母批校准名单、方法和校准文件的 SHA-256。两种见证读数共享两个登记时刻。确认前用实际设备验证时钟、空间响应核和相同截止前出值；若采集时间不同，单列总成本。按最高原始测量噪声和用途定义容差，模拟里的数值不继承。
2. `READINGS.json` 以原始母批为索引，记录五个共有早期值、两种见证读数各两个值、试样号、采集 UTC、实际出值 UTC 和冻结时间。共有五项是低活度和高活度各一次早期含水与总动员，以及一个干态近半层库存。厚度、配方、边界与电极几何由实验协议和原始记录关联。`inputs` 命令分别导出七项读数和请求，供各方法独立读取。用同一次无扰动扫描提取体均值与预定义局部带比较信息价值。若实际采集使用不同仪器或分开的扫描，需要另外记录代价，不能从相同字段数推断等成本。
3. `CHOICES.json` 记录每个母批、每个请求和每种方法的候选 ID，弃权用 `null`。先完成输入、候选及风险规则冻结，再做正式服役暴露。`freeze` 将协议、读数、决定及评分源码绑定。一方没有决定，仍保留该母批在端到端统计的分母。
4. `OUTCOMES.json` 记录每个被选候选的湿与弱湿主片。在固定湿读法下，若测量会破坏主片，先登记另一个**母批面板**任务再使用平行片。当前评分器验证同一主片的全窗结果，拒绝将不同试样的不同时间片拼成一条曲线。若两种方法选同一个候选，共享完全相同的主片测量。
5. `score` 输出按请求的判据、按母批的接受和失败区间、对独立母批等权的成功率。一次母批最多为条件风险统计贡献一个独立样本。按照用途需要，还应独立计算置信限并报告有用的方案数量。测量未决时保留上下界。

允许不同日期配制与运行母批。对每个实际批次块分开运行冻结和评分，保持 `PROTOCOL.json` 精确相同。用 `combine 合并输出.json 第一块评分.json 第二块评分.json` 给出母批等权统计。命令检查相同协议散列和无重复母批。每个块的原始冻结与评分文件仍单独保存。

主实验只需要在每个确认母批测两种方法实际选中的候选。在所有候选均有完整实测前，实物部分只能比较交付策略。精确枚举得到的可行上限属于模拟任务。

## 软件回放

`demo_window_confirmation/` 提供带合成标识的四个实例文件。示例数据用于测试输入隔离、时间表和数值判定。它没有材料测量或临床含义。以下命令从脚本目录运行，并使用新输出名。

```powershell
$d = 'demo_window_confirmation'
python -B validate_window_confirmation.py inputs "$d/PROTOCOL.json" "$d/READINGS.json" "$d/replay_inputs"
python -B validate_window_confirmation.py freeze "$d/PROTOCOL.json" "$d/READINGS.json" "$d/CHOICES.json" "$d/replay_frozen.json"
python -B validate_window_confirmation.py score "$d/PROTOCOL.json" "$d/READINGS.json" "$d/CHOICES.json" "$d/replay_frozen.json" "$d/OUTCOMES.json" "$d/replay_scored.json"
python -B -m pytest -q test_window_confirmation.py
```

首轮真实工作要补齐仪器输出、读数时间、层厚和湿／弱湿边界，约定从哪个材料坐标提取局部值，确定可接受的实际电流或导电值及力学阈值。随后冻结一个材料系统与用途，再决定配方和批次数。对于接受母批中零失败时的单侧 95% 上限，9.5% 约需要 30 个接受母批，5% 约需要 59 个。还需将预期接受率与实际试验功效纳入总批次数。此处数值只用于样本量规划。

## 把真实观测接入前向方程

在独立开发批选择固定时间、厚度、电导率和模量参考值 $t_0,L_0,\sigma_0,E_0$。内部输运系数的归一化为 $D^*=Dt_0/L_0^2$，边界传质为 $K^*=Kt_0/L_0$，量级随实际材料和装置标定。工作窗的实测穿厚度电导使用原始单位 S。固定面积、排除接触与旁路时，可与模型的 $G^*=GL_0/(A\sigma_0)$ 对应。生物电子实际工作所需的支撑、弯曲、湿接触以及电极极化由独立测量决定。前后层材料模量均值目前只是模拟用途代理。

厚度约束试验需要同平面面积的三个定厚模具和独立后处理。先测固化后／洗涤后干片的实际厚度和束缚离子的面库存，再用同批试片验证水化中厚度变化、有效传导截面与装夹一致性。固化时体积投料按厚度逆比例变化仅是提出同面库存的一种工艺假设。连续同剂量确认、设备上机时间和材料实际功用必须来自新制备母批。冻结一项已约定的主要用途，再用真实装置检查反馈和阈值。 [厚度模拟与敏感性](runs/patch_thickness_catalogue_20261117T021658657133Z/RESULTS_ZH.md)
