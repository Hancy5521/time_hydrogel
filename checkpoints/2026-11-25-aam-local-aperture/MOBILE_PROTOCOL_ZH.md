# 粗位置触发后的随机平移局部快照

固定视野的合格事件太少。这里保留每条见证最多三条高分辨记录、0.70 盒边视野、2.05 至 4.85 时段和相同位点／边缘标签假设，加一个覆盖全盒的粗反应中点定位器。定位器仅用于选择局部视野，估计器不接收其余区域的候选图。每次事件前状态的高分辨视野由触发记录回取，是理想计算采集能力，技术成本与固定视野不同。

设事件中点为 m，高分辨视野边长 L 的 0.70 倍。选取三轴独立均匀 d ∈ [r,L*0.70-r]，返回原点 o=m-d（周期坐标）。给定返回原点 o，在所有中点球完整位于其中的候选上，P(o|m) 采用相同的连续密度，条件化到该原点时这项在候选相对风险中抵消。用于采集的随机数独立于原生反应创新，按发生事件索引取值。二维暴露或非均匀位移需显式加入对应权重。观察器要求原局部图能确认桥连／闭合，使用与固定视野相同的标称候选校准。多余未采集事件的生存时段不进入部分似然。

从相同的单体初态和模拟地址，在一次轨迹中同时记录固定视野和移动视野；两者分别最多三条。新卡分组 112/48/112，先冻结校准与直接强基线，再采新见证确认。方向准确率、概率 Brier、采集利用率同时对照。沿预登记方案用新 C 地址测试公平能量，明确所有方法获得一样的四个基底坐标。验证原生状态和日志在启用观测时逐位不变。保留固定触发结果及两者差距。
