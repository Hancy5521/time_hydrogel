# 连续可编辑规则的局部反推与跨工艺原生预测

移动触发看见更多合格事件。下一独立试验把两档开关扩成连续曲线幅度 η∈[-1.10,1.10]。近似规则曲线在空走廊保持基底桥连强度，在非空走廊改变候选相对权重。保留随机平移采集、每条最多三记录以及原生时钟。拟合、开发、留出分别 112、48、96 个新基底；每卡用独立均匀幅度生成相反两方向和相同 A/B 见证种子。模型单分支独立预测，只在训练与计分组织成对。反向分支用于精度估计，实际使用不需要成对输入。

概率候选将模拟给出的合法本地风险按相对反应权重组织。对 b 的先验积分与对 η 的七节点网格给出强度分布。与同输入直接核近邻、直接核岭七节点概率回归、移动/固定的同条件似然、原快照核方法及无读数均匀先验公平比较。七节点网格代表计算精度，不限定真实幅度或后续模型的自由度。直接方法只使用其拟合卡的真实 η，拟合 C 轨迹不入模型。开发卡按规则幅度 CRPS 确定超参数。确认前冻结模型和超参。

规则预测主指标为确认卡的连续幅度 CRPS，报告 RMSE。过程主指标为两工艺的桥连与最大团簇四时点联合公平能量。预测时给定基底四参数给全部方法，在相同独立随机地址生成七节点轨迹，利用冻结权重组成物理轨迹分布。真值在未参与拟合的连续幅度及新 C 地址重启。时间表先沿用原生已冻早进及晚方案，无新湿实验。采用门按组报告是否优于固定四维且可达到同输入最强对照。已冻结任务下选择仍可能不需要个体化。
