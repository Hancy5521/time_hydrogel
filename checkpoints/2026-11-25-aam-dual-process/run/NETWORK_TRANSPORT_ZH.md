# 从成键历史计算方向性连接传输

这一读出检验同一微观成网轨迹能否建立连续路径，以及刚贯通和拥有多条贯通通路会有多大区别。模型按事件时刻更新图，分子是节点，原生共价成键事件给边。载入事件列以时间、标签、两个反应位点与三个整数周期偏移表示。形成链与交联、组合终止的标签 3、4、5、6、7、9 加边。初始投料、引发及歧化终止不加边。每个查询时刻只使用当时及此前的事件。

每条成键边赋单位电导。对一个方向施加跨周期盒单位势差，边 (e:uightarrow v) 上的势差为 (phi_v-phi_u+k_{e,a})，其中 (k_{e,a}) 为该轴的整数周期偏移。结构传输代理是
[
G_a = min_{phi}sum_e(phi_v-phi_u+k_{e,a})^2.
]
在每个分量固定一个顶点势作为参考，得到正定约化拉普拉斯。程序先沿生成树做精确整数规范变换。无绕行轴所有边的变换后偏移为零，输出精确零。其余轴求解 Kirchhoff 方程并回算各边能量。多分量能量相加。三个值是各方向施加单位势差的对角读出，未估计方向间耦合。 [随机网络的渗流与传输](https://doi.org/10.1103/RevModPhys.45.574) · [电阻网络的变分原理与单调性](https://arxiv.org/abs/math/0001057)

一棵跨坐标盒边界的树不能持续贯通，数值为零。长度 (m) 且绕行一次的环给 (1/m)，增加或并联冗余通路可能增加读出。固定周期长度、边权及已存在边时，新增边增加一个非负势差平方项，最小能量因此不减。这为不可逆成键模型提供时间单调性的数值检查。模型未包括真实电子、离子、含水、频率、非均匀边阻或电极几何，结果为无量纲的结构代理。实际电导率和材料功能时序仍需要同批测量与校准。物理模型若需导通后再次关闭，必须添加可检验的失效边、可逆键或时变载流响应。

实现以解析树、单环、并联和方向等效性测试验算。另用不同求解方式复核 180 张合成随机图。直接对完整矩形关联矩阵做 SVD 最小二乘，与约化拉普拉斯求解的最大差为 (2.14	imes10^{-14}) 以内。随机整数规范变换的输出差为零。添加单边最小数值差约为 (-3.6	imes10^{-15})，符合浮点误差。此收据生成时未读本轮确认日志。
