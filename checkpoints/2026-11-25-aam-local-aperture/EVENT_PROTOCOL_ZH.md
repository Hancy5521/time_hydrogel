# 局部合格反应触发采集与有限候选归一化

固定拍摄时点的完整邻域和可追踪端点共同约束过稀，留出后没有改善。第二条路线检验以局部成键作触发的观测。最多每条 A/B 轨迹收三个高分辨事件记录，视野边长仍为 0.70 倍盒边，时间限制 2.05 至 4.85。触发须具备理想化局部反应位点提示、有效候选近邻、可追踪的局部图和视野边缘的键端计数。它是一类更强的采集装置，持续触发成本与定时快照不等价。当前只构造数值观测模型，未声称实物仪器可以达到同样分辨率。

每次观测只使用两端在视野内、中点占据球完全可见的备选连接。原局部路径连通可证实环闭合，两端分属不同局部团簇且至少一端团簇无外连键端时可证实桥连。未知连接与未完整可见的邻域从风险集合移出。选中的真实反应必须在此集合内，并且候选的曲线敏感特征具有变化，才记一个触发事件。原生模型的标称近／远及谱系校准权重作为已知量，所有强对照均获得这些相同读数。全局候选集合、完整团簇标签、精确真实四坐标及 C 未来读取不给预测侧。观察器在数值层读取可见候选匹配和标称权重，明确强于普通空间快照；隐藏图只在事后确定观测是否正确的程序断言中用到。

设本地四组的标称风险为 R(z,k)，z 为空／拥挤，k 为闭环／桥连；同一观察窗下闭环指数 m=-.5，桥连 m=1。对给定基底常数 b 与条件规则 s，将组权重写成 R(z,k) exp(m(b+z*s)) 并除以这四组的总和。全箱的即时速率、第二位点速率的共同乘数和不可见候选均因给定事件属于本地集合而消去。以 b 在合法先验范围内积分，比较 s=±1.10。此处是标注观测成立时的部分似然，忽略未触发时段的额外信息。函数形式来自模拟机制，真实映射待标定。

新独立训练 112、开发 48、确认 112 张基础卡；每卡正反两规则均以 A/B 各四个地址生成。与同输入直接岭/RBF、同输入条件独立的四组频数及没有识别信息的先验对照。模型选择与平滑程度用开发卡，确认快照采集晚于冻结。冻结条件选择和基线后，才在同确认卡的全新不可见 C 地址比较桥连及最大团簇联合轨迹。所有对照获同一模拟的四个基底参数，目的是隔离额外新规则信息。最终采用门是公平、独立地址校正后的轨迹能量不高于最强同信息对照，并且优于固定四维。早/晚目标沿用冻结阈值，仅在得到真实决策空间的证据后再尝试替换固定选案。
