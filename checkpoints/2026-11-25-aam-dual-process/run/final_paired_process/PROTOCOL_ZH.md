# 同一微观前体的双目标独立确认

登记 UTC 2026-11-25T05:49:44.1620121+00:00，Asia/Shanghai 2026-11-25T13:49:44.1620121+08:00。只在悬挂位点分时控制独立确认通过后启动，不改之前两套完整目标及阈值。

用 48 张新四坐标前体卡、每卡 16 组与所有父轮及后续分支均独立的随机地址。每组共有五次从无接键单体的轨迹重启，并保持初态、布朗增量地址、等待随机数和选择随机数地址相同。早进策略取早期投料的冻结编号 15，同编辑的原环境静态对照编号 12。延迟策略取冻结悬挂编号 4，冷启动至 3.50 后恢复并提高悬挂反应强度。与冻结最佳的静态引发降载对照比较。无编辑一条路径共享给早/晚两种目标评分。所有控制的建模时间步统一由 .025 减半至 .0125。进场、场脉冲与时间测量边界及近邻计算方案不变。

主要终点分别为早进、延迟和同一母卡、同一随机地址两条独立控制模拟均联合达标。使用母卡 bootstrap 95% 区间。再报告在同一前体卡上两种控制随机地址独立时的达标率估计，为每卡两种边际率乘积后平均。无编辑两目标互斥，双达标率按定义为零。对照主要看冻结静态双动作避免无编辑的机械零作为有效性成败。另记录每张卡各控制首条完整稀疏事件日志，于轨迹终点和等转化位点独立回放，记录中段网络质量差及早/晚目标逐项指标。

此为模型总体控制验证。规则卡为仿真中的固定有效参数，策略从已冻结的总体最优菜单取出。没有据个体快照或留出真实材料选择策略。没有新增真实材料测量。
