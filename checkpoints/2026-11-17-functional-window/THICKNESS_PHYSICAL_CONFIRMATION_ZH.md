# 厚度方向的实物验证

验证问题是在相同干态平面面积和离子面库存下，改变厚度是否能让补片在规定安装时窗保持支撑，在工作时窗同时软化并恢复穿厚度电导，且弱湿对照不误触发。台架上的安装和工作合规是实物终点。上一轮的前后层模量、无量纲导电阈值来自模拟。 [既有冻结与评分接口](WINDOW_CONFIRMATION_EXECUTION_ZH.md)

## 先把厚度和库存做实

- 用同一聚合物原料、交联条件、干燥条件和层面面积制造基准、较薄和较厚主片。先导可用 $L_-=0.85L_0$、$L_0$、$L_+=1.15L_0$ 作模具目标，是否达到须由固化、洗涤和干燥后的实测确认。每个厚度记录中部与边缘干厚度、湿厚度随时间或在各原定读点的变化、前后层比例、盖层厚度、面积和卷曲。固定非厚度工艺的对照用于识别同配方中的几何作用。额外记录干聚合物面质量，防止把离子用量相同解读为所耗原料和体积相同。
- 先在开发批用 $c_{\rm feed}(L)=c_0L_0/L$ 估计体积投料，再用**服务暴露前、已完成标准化洗涤**的同母批兄弟片实测每单位干态面积的保留目标离子 $n_{\rm ret}/A_0$。全片消解或经回收率验证的充分提取可测总量。若着重区分束缚和自由离子，结合定时提取确定可移动份额，并报告该操作定义。用已知面积、空白聚合物、浴液背景和基质匹配的加标回收定量。先导建立测量不确定度和工程等效带，确认前冻结容差。同面库存的实测差及其不确定区间应落在此等效带内。 [水凝胶金属离子保留与 ICP-OES 释放实验](https://doi.org/10.1002/cplu.202300368)
- 湿与弱湿预先分别指定温度、配液、湿润面、封边、实际浴液体积、暴露方式和零时刻。同一环境在三个厚度使用固定的实际浴量，不按试片体积自动缩放。若弱湿用水蒸气边界，独立记录 RH、温度和意外凝结。若用有限浴取样，保留所有取出和补进液体的体积、浓度及时间。按元素或同位素区分原有离子与从浴液进入的同种离子；只能测净变化时保留这一解释。 [盐载凝胶泄漏实测](https://doi.org/10.1002/adma.202211783)

水槽近似充分混合时，第 $k$ 次取样前由湿浴测得的净离子量为

\[
N_{\rm bath}(t_k)=V_k c_k+\sum_{j<k}v_jc_j-V_0c_0-\sum_{j<k}v_jc_j^{\rm in}.
\]

式中 $V_k,c_k$ 为取样前实际体积和浓度，$v_j$ 为先前每次取出及补入的等体积，$c_j^{\rm in}$ 为补充液浓度。取出和补入体积不同时分别用实际值。以 $n_{\rm ret}-N_{\rm bath}-n_{\rm specimen}(t_k)$ 核对物料闭合，必要时加入夹具、封边或沉积取回的离子。初始本底和补液浓度均来自实测。 [有限采样补液的释放计量先例](https://doi.org/10.34172/bi.2023.24266)

## 用整片实际载荷评价安装支撑

用真实安装模拟夹具和代表性工作基底，冻结受力位置、夹持长度、载荷／位移速度、持续时间及允许挠度或最小维持力。安装段主判据在例如恒定模拟载荷下，整片挠度在阈值内且未发生滑移、皱折、屈曲或脱夹。工作段先锁定用途相关的整片顺应性判据，例如用相同触头、同速度低载测力–位移斜率的最大值，或者规定基底曲率下的贴合载荷上限。用独立先导批验证反复小载荷、光学跟踪和电学轮询不会改变吸水、卷曲和通量，再在原位跟踪同一主片。必须更换夹具或破坏测量时，预登记同母批面板任务。 [Park 等直接测水凝胶混合器件弯曲和 dry/wet 安装](https://doi.org/10.1038/s41467-021-23802-9)

对均匀、同宽、线弹性、小挠度的悬臂条，端部刚度为 $K=3EI/\ell^3$，其中 $I=bL^3/12$。即使材料模量相同，0.85 倍厚度的弯曲刚度也仅约为 0.614 倍，1.15 倍厚度约为 1.521 倍。分层小应变纯弯曲可用 $b\int_0^{L(t)}E(z,t)(z-z_N)^2\,dz$ 解释，$z_N=\int zE\,dz/\int E\,dz$，其中 $E$ 要与加载速率和湿态相符。存在层间滑移、明显预弯或黏弹松弛时，直接用整片台架读数判定。安装是承托、剪切或贴附时，按实际载荷模式测对应反力和位移，悬臂公式只作几何敏感性。 [梁与夹层截面推导](https://ocw.mit.edu/courses/2-080j-structural-mechanics-fall-2013/de27f1d8f647ff995771d4b8d48d34bc_MIT2_080JF13_Recitation5.pdf)

## 电学、时间和因果对照

- 使用两面对置电极和绝缘护环，固定电极法向压力、接触面积和频域分析规则，同时记录受压湿厚度 $L_{\rm wet}(t)$、有效通流面积 $A_{\rm eff}(t)$、原始复阻抗与温度。用短路／开路、无样片湿浴、绝缘片以及已知贯穿电导的基准检验导线、侧旁路和界面。可在独立校准片改变接触压力检查接触偏差，同一装夹压力下仍需考虑不同厚度的压缩量。将事先验证的体相阻值 $R_b$ 转成 $G=1/R_b$ 和可选的 $\sigma=G L_{\rm wet}/A_{\rm eff}$。前者按器件工作条件判时窗，后者用于比较材料。在层状湿片内仅一维串联近似下有 $R_b=A_{\rm eff}^{-1}\int dz/\sigma(z,t)$。电极极化或湿浴旁路未能分离的时点保留未决。使用实测受压湿几何进行换算。 [Heimerdinger 等穿厚度阻抗台架](https://doi.org/10.3390/membranes9050062)
- 保持同母批的局部和整片早期信息比较使用同次扫描与相同见证片，限定输出到冻结前可用的七项标量。真实局部水当量使用独立校准，外液中盐量使用化学测量，功能通道使用主片实际电学与力学。预先加密安装结束、工作开始和工作结束附近的采样，并保留工作窗中段。按实际暴露时间判定，不用是否达到已知后期信号择时。真实阈值从用途和装置确定。
- 先导可用三个独立称量和配制的母批，每批三种厚度与两种环境共 18 张主片，另用入库消解、空白和无扰动验证片。早期见证、盲化的功能结果和候选选择都保留母批、制备、试片和时钟身份。先导确认可测性和实际公差。正式独立批在规定库存范围和同候选数下比较冻结策略，母批内配对汇总，向外推前单独估计正式样本量。固定厚度对照验证整个目录的可达性时需完整枚举实测候选。只测冻结策略实际选到的候选时，比较的是可交付策略。

## 实物夹具评分器

用 [validate_patch_fixture_confirmation.py](validate_patch_fixture_confirmation.py) 冻结整片力学终点。原来的模量协议仍可用于原记录复算。新协议沿用 [原始包结构](WINDOW_CONFIRMATION_EXECUTION_ZH.md) 中的母批、七项早期读数、候选选择、湿／弱湿主片和实际暴露时钟。协议新增 `endpoint_contract = "patch_fixture_v1"` 和 `setup_sha256`。后者绑定另存的夹具、载荷、设备验证、侧旁路和测量步骤记录。`limits` 仅留 `off_siemens`、`on_siemens`、`weak_siemens`。在 `fixture_metrics` 的 `installation` 和 `working` 各提前选一个量，写入 `channel` 和同单位的 `limit`。

| 阶段 | 通道 | 单位 | 判定 |
|---|---|---|---|
| 安装 | `holding_load` | N | 当次在规定位置和持续时间内证实能维持的载荷，须达到下限 |
| 安装 | `holding_deflection` | m | 在规定载荷与位置下测得的挠度，须低于或等于上限 |
| 工作 | `working_compliance` | m/N | 在规定力率和位移范围下测得的顺应性，须达到下限 |
| 工作 | `conformance_load` | N | 达到登记的基底曲率或形状所需载荷，须低于或等于上限 |

用实际传感器记录维持载荷或形变的上下界。计划测试载荷不是已维持的载荷。工作期贴合未达到登记几何时，保留实际可判定的界和原始事件证据。若断裂、脱夹或滑移使该力学量失去定义，记为缺测并保留原因，不用失去接触后的零反力作为低贴合载荷。程序对无法判定的缺测保留未决，不能给综合达标结果。定量阈值、是否连续记录、夹具规格与失败事件均以真实设备先导登记，禁止把测试中的占位阈值沿用到实际材料。

```powershell
python -B validate_patch_fixture_confirmation.py inputs PROTOCOL.json READINGS.json isolated_inputs
python -B validate_patch_fixture_confirmation.py freeze PROTOCOL.json READINGS.json CHOICES.json FROZEN.json
python -B validate_patch_fixture_confirmation.py score PROTOCOL.json READINGS.json CHOICES.json FROZEN.json OUTCOMES.json SCORED.json
python -B validate_patch_fixture_confirmation.py combine MERGED.json BLOCK_01_SCORED.json BLOCK_02_SCORED.json
```

确认每个 `physical_pilot` 的冻结时间先于主片暴露。程序在各登记时点按湿或弱湿主片读数判断，区间跨阈值或关键读数缺失会留下未决。新旧 27 项软件测试均通过，覆盖中段力学失败、缺测与迟测、错误单位、湿与弱湿主片混用、试片拼接、冻结后阈值篡改。 [实物夹具软件测试](test_patch_fixture_confirmation.py)

### 先测薄见证片的可用信息

薄见证片是测量装置选项。成品候选几何仍按独立登记的产品方案。在先导母批上并行测标准厚度与 0.65 倍目标厚度，两个见证片保持固定暴露面积、实测离子面库存和浴液。登记每个见证片的实际面积、薄厚和厚度变化，比较电学测量的检测下限、局部扫描对水化／接触的扰动及获得电导所需的时间。模型的 0.4、0.8 都是无量纲时刻，应先以实际时钟选两项早期记录并确保读数在制程截止前出具。

若前述检查支持薄片，在同一薄见证片上比较局部含水连续两时点与第一时点含水、第二时点穿厚度电导。配置 `witness_units` 为 `{"depth": ["fraction", "fraction"], "depth_electric": ["fraction", "S"]}`，并使各方法的 `view` 与键一致。输入按方法隔离，原始电导保持真实单位 S。模型如需转成标准化对数电导，应在试验前冻结参考值与测量误差。实际噪声会影响信号是否有用。在等价两状态且近似高斯条件下，单读数达到平均 10% 二选一误差需要 ( |\mu_1-\mu_2|/\sigma\ge2.56 )。这可作检测设备的初步灵敏度目标，整窗选择风险仍由独立母批检验。 [紧时窗的模拟检验](TIGHT_WINDOW_REVIEW_RESPONSE_ZH.md)
