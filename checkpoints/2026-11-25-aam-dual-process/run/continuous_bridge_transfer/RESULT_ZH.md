# 连续桥连码的同预算预测迁移

沿用五帧原生 A/B 局部轨迹，每个读出取三帧。新生成 100 张开发、56 张留出卡，共 1,248 条 A/B 轨迹。第四个桥连坐标由 ±.70 两档改为 [-.70,.70] 的连续均匀分布。早期及后移分别拟合独立的岭和 RBF，只有局部值进入拟合。C 环境按预登记给出前三项真实码，专门检验第四项。每卡各以 24 条新路径估计预测和真值分布。解封连续桥连真码前已固定所有 6,720 条 C 预测，之后用新随机地址作 1,344 条原生独立重启。

| 读出 | 桥连码 MSE | C 桥连及谱系长度联合分数 | C 终点桥连 MAE | C 最大团簇 MAE |
| --- | ---: | ---: | ---: | ---: |
| 早读岭 | .175208 | .256253 | .025191 | .037365 |
| 晚读岭 | .163377 | .255701 | .023438 | .035886 |
| 早读 RBF | .183027 | .256132 | .024979 | .037593 |
| 晚读 RBF | .143566 | .255327 | .024022 | .037431 |
| 保持桥连码为零 | .139286 | .254907 | .023065 | .036792 |

越低越好。相同 RBF 的后移读出把连续桥连码 MSE 降低 **.039461**，约 **21.6%**，按材料卡配对的 95% 区间为 [.016568, .064581]。在 C 的桥连和谱系长度轨迹联合分数上，同一改动降低 **.000805**，约 **0.31%**，95% 区间 [.000055, .001576]。保持桥连码为零的简单对照在这两个量上更低，差值区间包含零。岭的后移方向相同，区间包含零。终点桥连与最大团簇没有明确增益。

由此支持一条有限联系。晚取同数量空间快照，可以改进同算法对连续桥连偏置的估计，并改善它在 C 中的联合轨迹预测。然而改进仍不足以超越零码强对照。C 迁移是隔离一个坐标的模拟正对照。前三个规则已知，且此次没有据预测选用新材料干预。在总目标上仍需四坐标的同信息独立增益和最终过程选案证据。
